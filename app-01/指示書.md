# 📝 GitHub Copilot用 指示書（AIプロンプト）

以下の仕様と要件に基づいて、チェロの練習に活用できるWebアプリケーション「チェロ練習用：楽譜付きコード進行・伴奏ジェネレーター」のコード（`index.html`, `style.css`, `script.js`）を段階的に作成・提案してください。
※複雑になりすぎないよう、スモールスタート（MVP：最小限の製品）を意識したシンプルで分かりやすいコード構成にしてください。

## 1. プロジェクト概要

* **アプリ名**: チェロ練習用：楽譜付きコード進行・伴奏ジェネレーター
* **目的**: チェロ奏者（初心者〜中級者）が、美しい和音（ハーモニー）の響きや低音のベースラインを確認しながら、ピッチ（音程）感やボウイング・移弦の練習を行えるWebアプリ。
* **特徴**: 外部の楽譜ファイル（MusicXML等）のアップロードや事前準備は一切不要。JavaScript内にあらかじめ定義した「著作権切れ（パブリックドメイン）の名曲コード進行プリセット」とロジックのみで完結する。
* **ターゲット**: チェロの個人練習に伴奏や和音の響きを取り入れたい演奏者・学習者。

## 2. 技術スタック・仕様

* **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
* **スタイリング**: Tailwind CSS（CDN経由で導入）
* **楽譜描画**: VexFlow（CDN経由で導入。予期せぬアップデートによる動作不良を防ぐため、可能な限りバージョンを指定したCDN URLを使用すること）
* **サウンド再生**: Web Audio API（ブラウザ標準機能を使用し、外部音源ファイルなしでチェロの音域に馴染む温かい和音・ベース音を鳴らす）
* **データ保存**: データベースは使用せず、お気に入り設定や練習履歴は `localStorage` を使用してブラウザに保存・読み込みする。
* **ホスティング**: GitHub Pages（静的サイトとして公開）
* **ファイル構成**:
  * `index.html`（画面の構造・UI・CDNの読み込み・フッターの免責事項）
  * `style.css`（Tailwindで対応できないカスタムスタイルや微調整用）
  * `script.js`（安全なプリセットデータ、コード進行生成ロジック、VexFlowによる描画処理、Web Audio APIによる音声再生、localStorage管理、イベントリスナー）

## 3. 著作権・安全性に関する設計ルール（重要）

* **著作権侵害の防止**: 自由記述による曲名検索や、著作権が存続している現代楽曲の再現は一切行わない。
* **パブリックドメイン楽曲への限定**: プリセット選択肢は、開発者側であらかじめ定義した「完全に著作権が消滅しているクラシック楽曲・民謡（パブリックドメイン）」のみに限定する。
* **免責事項の表示**: `index.html` のフッター等に「本アプリに収録されている楽曲およびコード進行はパブリックドメイン（著作権消滅済み）または音楽理論に基づく汎用的なものであり、特定の著作権を侵害する意図はありません」という旨の注意書きを小さく表示する。

## 4. 実装する主な機能（チェロ練習用・スモールスタート版）

1. **入力・選択パネル**:
   * **曲・プリセットの選択**: セレクトボックスから以下の安全な4つの楽曲プリセットを選べるようにする。
     1. 「カノン（パッヘルベル作曲）」（美しい循環コード・低音ベースラインの練習用）
     2. 「主よ、人の望みの喜びよ（バッハ作曲）」（3拍子のリズム感・滑らかな移弦の練習用）
     3. 「オーラ・リー（アメリカ民謡）」（穏やかなバラード調・ロングトーンの練習用）
     4. 「無伴奏チェロ組曲 第1番 プレリュード（バッハ作曲）」（分散和音・アルペジオの響き確認用）
   * **キー（調）の選択（移調機能）**: 原曲のキーに加え、チェロの開放弦（C, G, D, A）が響きやすい調（C major, G major, D major, A minor 等）へ切り替えて練習できるセレクトボックス。
   * **テンポ（BPM）の調整**: ゆっくり練習できるよう、スライダーまたは数値入力（例: BPM 50〜120）で再生速度を変更できる機能。
   * 「楽譜と伴奏を表示する」ボタン。

2. **データ構造のイメージ（`script.js`）**:
   以下のように、パブリックドメインの4曲をプリセットデータとして定義して管理する。

   ```javascript
   // パブリックドメイン（著作権フリー）のチェロ練習用プリセットデータ
   const celloPresets = {
       canon: {
           name: "カノン（パッヘルベル作曲）",
           category: "クラシック（パブリックドメイン）",
           description: "美しい循環コード。低音の響きとピッチの安定を確認するのに最適です。",
           defaultKey: "D",
           chords: ["D", "A", "Bm", "F#m", "G", "D", "G", "A"]
       },
       jesuJoy: {
           name: "主よ、人の望みの喜びよ（バッハ作曲）",
           category: "クラシック（パブリックドメイン）",
           description: "3拍子の流れの中で、移弦と和音の移り変わりを滑らかに練習できます。",
           defaultKey: "G",
           chords: ["G", "C", "D7", "G", "Em", "Am", "D7", "G"]
       },
       auraLee: {
           name: "オーラ・リー（アメリカ民謡）",
           category: "民謡（パブリックドメイン）",
           description: "穏やかなテンポで、豊かなロングトーンと弓のコントロールを養います。",
           defaultKey: "G",
           chords: ["G", "A7", "D7", "G", "G7", "C", "Cm", "G"]
       },
       celloSuitePrelude: {
           name: "無伴奏チェロ組曲 第1番 プレリュード（バッハ作曲）",
           category: "クラシック（パブリックドメイン）",
           description: "分散和音（アルペジオ）の骨格となるコード進行と響きを確認できます。",
           defaultKey: "G",
           chords: ["G", "C/G", "D7/G", "G", "Em", "A7", "D", "G"]
       }
   };
   ```

3. **コード進行・楽譜表示エリア**:
   * 選択された曲の説明（練習のポイント）と、コード進行（例: `D → A → Bm → F#m ...`）を大きく分かりやすく表示。
   * **VexFlow** を使って、各コードの構成音（和音）を五線譜（ヘ音記号、またはト音記号）として画面上に描画する。

4. **再生・試聴機能（チェロ伴奏モード）**:
   * 「再生」ボタンを押すと、設定したテンポ（BPM）に合わせて、生成されたコードの和音（チェロの音域に合う温かみのある低音〜中音域のサイン波・三角波など）が順番に鳴る（Web Audio APIを使用）。
   * 「停止」ボタンで再生を止められる。

5. **保存・履歴機能**:
   * よく練習する曲とキー・テンポの組み合わせを「練習リストに保存」ボタンで保存できる。
   * 保存したリストを画面下部に表示し（`localStorage` から読み込み）、クリックすると再度その設定で楽譜と伴奏が呼び出される。削除ボタンも用意する。

## 5. 開発の進め方（Copilotへの依頼順序）

一度にすべてのコードを書くと複雑になるため、以下のステップで順番に作成してください。

* **ステップ1**: 全体の土台となる `index.html`（Tailwind CSSとVexFlowのCDN読み込み、フッターの免責事項を含む）と、落ち着きのある見やすいUIレイアウト（`style.css`）の作成。
* **ステップ2**: `script.js` に上記の4曲のプリセットデータを定義し、曲やキー・テンポを選択したら画面にコード名と練習ポイントが表示される機能の実装。
* **ステップ3**: VexFlowを使って、表示されたコードに対応する五線譜を画面に描画する機能の追加（チェロ向けのヘ音記号表示にも対応できると尚良し）。
* **ステップ4**: Web Audio APIを使って、指定したBPMでコードの和音を鳴らす再生機能の追加。
* **ステップ5**: `localStorage` を使ったお気に入り練習メニューの保存・呼び出し・削除機能の追加。

まずは**ステップ1の `index.html` と基本的な `style.css` のコード**から提案してください。
